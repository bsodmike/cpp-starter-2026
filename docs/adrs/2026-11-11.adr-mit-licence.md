# MIT licence

- Status: accepted
- Date: 2026-11-11

## Context

The PRD left the licence open between MIT, Apache-2.0 and proprietary.

## Decision

MIT. The `LICENSE` file holds the full text, `vcpkg.json` carries
`"license": "MIT"` as an SPDX identifier, and the README links both.

## Consequences

- Permissive and short, with no NOTICE file to maintain and no attribution
  obligations beyond keeping the copyright notice.
- No explicit patent grant. Apache-2.0 would provide one; if this project ever
  ships patent-relevant work, or a contributor's employer requires an explicit
  grant, that trade needs revisiting in a new ADR. Relicensing MIT to
  Apache-2.0 is straightforward while the contributor set is small, and gets
  harder as it grows.
- Compatible with the dependencies currently in the allowlist (GoogleTest is
  BSD-3-Clause, google/benchmark is Apache-2.0).
- `docs/dependencies.md` keeps copyleft and source-available licences out
  without an ADR, so the distribution story stays simple.
